# Sticky Notes for PowerPoint

Yellow sticky notes you can put right on top of your slides.

## Why

PowerPoint's built-in comments sit in a side pane, out of sight. On a busy deck it's easy to miss them, lose track of which slide they belong to, or forget to reply.

Real sticky notes work because you can't miss them. They sit right on the page, where the feedback applies. This add-in brings that to PowerPoint: a bright yellow note on the slide itself, easy to see, easy to answer, and easy to clear away when you're done.

## What it does

Two controls on the Home tab: **Add Note** and a **Notes** menu (which also includes Add Note).

| Command | What it does |
| --- | --- |
| **Add Note** | Adds a note to the top corner of the current slide, ready to type into. |
| **Previous / Next** | Jumps to the previous or next slide that has a note, wrapping around at the ends. |
| **Toggle Done** | Marks the selected notes done (or all on the slide): a faint tint, a ✓, and an optional "— Done FL · Oct 23" stamp. If they're all done already, reopens them. |
| **Delete** | Deletes the selected note, or all notes on the current slide if none is selected. |
| **Delete Done** | Deletes every done note in the deck, after asking for confirmation. |
| **Delete All** | Deletes every note in the deck, after asking for confirmation. |
| **Hide All / Show All** | Hides or shows every note in the deck, for example before presenting. |
| **Open Pane** | Opens the side panel: a checklist of all notes by slide (tick to mark done, click to jump), a progress bar, messages and settings. |

Notes are ordinary shapes saved in the deck. They travel with the file and are visible to anyone who opens it, even without the add-in. They also appear when you present or print, unless you hide them first.

## Settings

Settings are in the Sticky Notes pane, under **Settings**. They're saved for you on the device you set them on, so your PC, Mac and browser each keep their own. They change how *new* notes look and behave; existing notes stay as they are unless a setting says otherwise.

### New Notes

| Setting | Options | What it does |
| --- | --- | --- |
| **Position** | Top Left, Top Center, **Top Right** (default) | Where a new note appears, flush against the top edge of the slide. If a note already sits in that spot, the next one cascades 0.25 in down (and inward from a corner) into the first free spot. Notes elsewhere on the slide, or ones you've dragged away, don't push new notes down. |
| **Color** | **Yellow** (default), Pink, Blue, Green, Orange, Purple | The fill of new notes, with a slightly darker border of the same color. Existing notes keep their color. |
| **Apply [Color] to All Notes** | A link under the swatches | Recolors every note in the deck to the chosen color in one step. Done notes keep their done look, tinted with the new color. |
| **Prefix** | Any text up to 20 characters, e.g., `FL:` (empty by default) | Starts every new note with your prefix, e.g., "FL: Note", with the word "Note" selected so you can type straight over it. Leave it empty for a plain "Note". |

### Done

| Setting | Options | What it does |
| --- | --- | --- |
| **Done Stamp** | On / **Off** (default) | When on, marking a note done adds a last line such as "— Done FL · Oct 23", so others can see who closed it and when. Reopening the note removes the stamp, as long as the line hasn't been edited. |
| **Who** | Any text up to 20 characters, e.g., `FL` | The name or initials in the stamp. If it's empty, the stamp uses your Prefix without its trailing colon; if both are empty, it shows the date only ("— Done Oct 25"). |
| **Skip Done Notes** (Done Navigation) | **On** (default) / Off | When on, Previous and Next jump only between slides that still have open notes, and say "No open notes" when everything is done. When off, they visit every slide that has notes. |

## Requirements

- Microsoft 365 PowerPoint on **Windows, Mac or the web**
- Hide All / Show All need a recent build (PowerPoint JavaScript API 1.10)
- PowerPoint for iPad can show and edit notes, but the buttons aren't available there

## Privacy

The add-in runs entirely inside PowerPoint. Note text stays in your presentation file. Nothing is sent to this site or anywhere else; this repository only hosts the add-in's code and icons.

## Installing

### For organizations

A Microsoft 365 administrator deploys Sticky Notes through **Admin center → Settings → Integrated apps → Upload custom apps**, using the manifest file. Once deployed, it appears on the Home tab in PowerPoint for the assigned users.

### On your own (any Microsoft 365 plan, including Personal and Family)

All three options use the same manifest file. First, download it: open [manifest.xml](https://leefc01.github.io/sticky-notes/manifest.xml), then save the page as `manifest.xml` (right-click → Save as).

Microsoft describes these as testing and sideloading methods. They work, but you may occasionally need to repeat a step, for example after clearing browser data. Updates to the add-in's code reach you automatically.

#### PowerPoint for the web

1. Open any presentation at [office.com](https://www.office.com).
2. Go to **Home → Add-ins** (on some versions it's under **Insert → Add-ins**, or in the **⋯** overflow of the ribbon).
3. Select **More Add-ins** (or **More Settings**), open **My Add-ins**, and choose **Upload My Add-in** (top right).
4. Browse to `manifest.xml` and select **Upload**.

#### PowerPoint for Windows

1. Create a folder, for example `C:\OfficeAddins`, and put `manifest.xml` in it.
2. Share the folder: right-click it → **Properties → Sharing → Share**, then note the **network path** (for example `\\YOUR-PC\OfficeAddins`).
3. In PowerPoint, go to **File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs**.
4. Paste the network path into **Catalog Url**, select **Add catalog**, tick **Show in Menu**, then **OK**.
5. Restart PowerPoint. Go to **Home → Add-ins** (or **Insert → My Add-ins**), open **Shared Folder**, choose **Sticky Notes**, then **Add**.

#### PowerPoint for Mac

1. In Finder, choose **Go → Go to Folder** and enter:
   `~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef`
   If the `wef` folder doesn't exist, create it.
2. Copy `manifest.xml` into that folder.
3. Restart PowerPoint. Go to **Insert → Add-ins → My Add-ins** (or **Home → Add-ins**) and choose **Sticky Notes**.

#### Good to know

- The add-in's code is served from this site, so it always runs the latest published version. The version is shown at the bottom of the Sticky Notes pane.
- Hide All / Show All need a recent Microsoft 365 build; older builds show a message instead.

## Uninstalling

Removing the add-in doesn't remove notes already in your decks. They stay as ordinary shapes. To clear them, run **Delete All** in each deck *before* uninstalling, or delete them by hand afterward.

- **Organizations:** a Microsoft 365 administrator opens **Admin center → Settings → Integrated apps → Sticky Notes** and removes it, or edits **Users** to remove specific people. It can take up to 24 hours to disappear from PowerPoint.
- **PowerPoint for the web:** go to **Home → Add-ins → More Add-ins** (or **More Settings**), open **My Add-ins**, select **⋯** on Sticky Notes, then **Remove**.
- **PowerPoint for Windows:** go to **File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs**, select the Sticky Notes catalog path, choose **Remove**, then **OK** and restart PowerPoint. You can then delete the shared folder.
- **PowerPoint for Mac:** in Finder, choose **Go → Go to Folder**, enter `~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef`, delete `manifest.xml`, then restart PowerPoint.
